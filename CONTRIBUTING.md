# Contributing to Job Find India

Thank you for your interest in contributing to Job Find India! We welcome community contributions to help improve the scrapers, regional mappings, and UI experience.

## Code of Conduct

We expect all contributors to follow our [Code of Conduct](CODE_OF_CONDUCT.md) in all community spaces.

## How Can I Contribute?

### Reporting Bugs
* Open a GitHub issue detailing the bug.
* Include steps to reproduce, search query/location keywords, and expected vs. actual behaviors.
* Attach screenshots or copy-paste logs if applicable.

### Suggesting Enhancements
* Check the current roadmap in the `README.md` first.
* Open an issue explaining the proposed feature, its benefits, and how it aligns with the project goals.

### Code Contributions (Pull Requests)
1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/cool-enhancement`.
3. Implement your changes. Preserve backwards compatibility for all APIs and components.
4. Run all unit tests to make sure everything passes:
   ```bash
   python -m pytest
   ```
5. Commit your work and open a Pull Request explaining what the changes accomplish.
